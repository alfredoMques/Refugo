# Refugo
Dashboard visual para avaliação/simulação de refugo (projeção do PPM de fim de ano — BU1 SA).

## Como executar

```bash
pip install -r requirements.txt
streamlit run app_refugo_v3.py
```

Envie a planilha no layout "Dados brutos" pela barra lateral (ou coloque `Dados brutos.xlsx` na pasta do app).
